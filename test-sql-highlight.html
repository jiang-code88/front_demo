SQL Tools — 测试页

CodeMirror 6 多 Tab 独立查询 / AJAX 提交 / 自动补全验证

使用说明： 安装 Tampermonkey 脚本 tampermonkey-sql-highlight.user.js 后，本页面会自动加载 CodeMirror 6 SQL 编辑器。本页面用 window.fetch mock 了 sqltools（提交/分页） 与 get_database_tokens（自动补全）两个接口，可以在完全离线的情况下验证： 多 Tab 独立查询结果、切换 Tab 联动数据库选择、分页、报错渲染、双击重命名、Ctrl+空格触发的字段补全。 数据库选 error_db 会模拟报错；选 demo_db 会返回 3 页假数据。
