SQL Highlight 脚本测试页

安装油猴脚本 tampermonkey-sql-highlight.user.js 后，在下方的 textarea 中输入 SQL， 将自动激活语法高亮。

场景 1 · SELECT 查询（页面加载即有内容，应自动激活高亮）

包含 JOIN、子查询、窗口函数、注释，覆盖常见语法结构。

提示：脚本检测到 SELECT 起始关键字后自动增强此 textarea。

场景 2 · 空白输入框（输入 SQL 后自动激活）

在下方输入框中逐步输入 SQL，防抖 500ms 后触发检测，自动激活高亮。

停止输入 0.5 秒后检测；或者输入后点击旁边区域再聚焦也会触发检测。
